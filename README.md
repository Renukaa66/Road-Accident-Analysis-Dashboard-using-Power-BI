# 🚦 Road Accident Analysis Dashboard

## 📌 Overview

This project focuses on analyzing road accident data using Power BI to uncover key patterns, trends, and insights. The dashboard provides an interactive and user-friendly interface to explore accident statistics and improve decision-making.

## 🎯 Objectives

* Analyze accident trends over time
* Identify high-risk locations and conditions
* Understand accident severity distribution
* Provide actionable insights for safety improvements

## 🛠️ Tools & Technologies

* Power BI
* Microsoft Excel / CSV Dataset
* Data Cleaning & Transformation

## 📊 Key Features

* Interactive dashboard with filters and slicers
* Year-wise and region-wise accident analysis
* Severity classification (Fatal, Serious, Minor)
* Visual insights using charts and graphs

## 📈 Key Insights

This dashboard helps in understanding road accident patterns and supports data-driven decisions to improve road safety.
